# Tín hiệu đáng capture

Quét hội thoại và công việc, tìm 3 nhóm tín hiệu, map sang 3 loại entry.

## Fact (F-): cần nhớ gì khi làm

- Gặp gotcha mất thời gian thử sai mới ra.
- Quy tắc hoặc cú pháp dễ quên, vd cú pháp CLI khác thường.
- Quyết định có lý do, sau dễ quên vì sao chọn vậy.

Câu hỏi kiểm tra: "lần sau gặp lại có cần nhớ cái này không?".

## Map (M-): khi nào dùng tool nào, thứ tự ra sao

- Một trình tự thao tác đã làm 2 lần trở lên.
- Chuỗi bước có thứ tự, mỗi bước dùng tool hoặc skill khác nhau.

Câu hỏi kiểm tra: "mình có lặp lại quy trình này không?".

## Tool (T-): làm việc X thế nào

- Skill có sẵn yếu, thiếu, cho output không đạt. Đặt `subtype: improve`.
- Khoảng trống năng lực, cần skill mới. Đặt `subtype: new`.

Câu hỏi kiểm tra: "có công cụ nào nên sửa hoặc tạo mới không?".

## Khi mơ hồ giữa Fact và Map

Một sự kiện đơn lẻ thì ghi Fact. Một chuỗi bước có thứ tự thì ghi Map.

## Hai ngả capture

- Thủ công: user gọi capture hoặc nói "ghi nhớ cái này".
- Gợi ý cuối phiên: khi task xong, liệt kê đề xuất "nên capture X vào nhóm Y", user duyệt rồi mới ghi. Không tự ghi lén.
