## Sự kiện / quy tắc

Khi dùng **Workers Builds** (Git integration trên Cloudflare dashboard), deploy command là `npx wrangler deploy`. Lệnh này đọc `wrangler.jsonc` trong repo. Nếu thiếu file → deploy fail không rõ lý do.

Với static site (Vite build ra `dist/`), config tối thiểu:

```jsonc
{
  "name": "ten-project",
  "compatibility_date": "2026-06-06",
  "assets": { "directory": "./dist" }
}
```

Verify bằng dry-run trước khi push: `npx wrangler deploy --dry-run`. Phải thấy "Read N files from the assets directory".

## Khi nào liên quan

Mỗi lần deploy static site (Vite, CRA, Next.js export...) lên Cloudflare Workers qua Git integration.
