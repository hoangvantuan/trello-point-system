## Sự kiện / quy tắc

Sau khi kết nối repo GitHub với Cloudflare Workers Builds (Git integration):
- Mỗi `git push` lên **production branch** (`main`) → Cloudflare tự chạy: clone → `npm install` → build command → deploy command. Không cần thao tác tay.
- Branch khác (nếu bật "Builds for non-production branches") → tạo **preview URL riêng**, không đụng production.
- **URL production cố định** qua các lần deploy, không đổi. Nên chỉ cần cập nhật connector URL trong Trello một lần duy nhất.
- Lần đầu vẫn phải push thủ công để đưa file config lên GitHub.

## Khi nào liên quan

Sau khi thiết lập Git integration với Cloudflare. Cũng hữu ích khi giải thích cho team về quy trình CI/CD.
