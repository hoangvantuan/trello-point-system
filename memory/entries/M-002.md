## Mục tiêu workflow

Một bản đồ tra cứu duy nhất khi build hoặc sửa Power-Up này, gom mọi đặc thù iframe/deploy/REST/UI vào một chỗ để không vấp lại các gotcha đã ghi. Mỗi bước trỏ tới Fact chi tiết.

## Trigger

Khi thêm/sửa bất kỳ phần nào của Power-Up: đăng ký connector, layout popup/modal, fetch dữ liệu qua REST, dashboard, hoặc cấu hình security header.

## Trình tự (bản đồ)

1. **Hạ tầng deploy** → F-019: Cloudflare Workers Builds cần `wrangler.jsonc`, tự build+deploy mỗi `git push`, URL production cố định. Security/CSP header đặt qua `public/_headers` (Vite copy sang `dist/`), dùng `frame-ancestors` KHÔNG `X-Frame-Options` → F-018.
2. **Đăng ký connector** → F-003: iframe connector URL trỏ `/index.html` (bắt buộc HTTPS); popup mở qua đường dẫn tương đối `./popup.html`, KHÔNG khai báo riêng trên Trello admin.
3. **UI chrome popup/modal** → F-016: Trello tự vẽ title bar (đừng lặp tiêu đề); modal height cố định, bỏ mọi `t.sizeTo()` (chỉ hợp lệ ở popup, ném `PostMessageIO:NotHandled` trong modal). Đừng để bar dung lượng pluginData (x/4096) cạnh tranh spotlight với tiến độ point → F-006.
4. **Đọc dữ liệu qua REST** → F-017: bulk-fetch pluginData mọi card 1 request `GET /1/boards/{id}/cards?filter=all&pluginData=true`; chọn `filter=all` (gồm archive) vs `visible` tùy ngữ nghĩa. Codec `value`: `est` + `log_<memberId>`, trần 4096 ký tự → F-021. Iframe phụ phải truyền `appKey`/`appName` khi `getRestApi()` → F-010.
5. **Dashboard / thống kê** → F-011: layout responsive (bảng cuộn trong `.sheet`, breakdown bar co lại trong iframe hẹp). Phân biệt tab **stock** (List — KHÔNG filter thời gian) vs **flow** (User — filter đúng nghĩa) → F-014.
6. **Verify**: `npx tsc --noEmit` + `npx vitest run`; security header verify trên **live** bằng securityheaders.com sau khi deploy (build cục bộ không tự verify được).

## Cạm bẫy / lưu ý

- `t.sizeTo()` trong modal ném `PostMessageIO:NotHandled`, kéo sập init dù data đã load (F-016).
- `filter=visible` loại card archive → thống kê tích lũy sai nếu cần gồm archive (F-017).
- `X-Frame-Options` chặn Trello nhúng cross-origin → Power-Up vỡ hoàn toàn (F-018).
- Header chỉ áp dụng SAU deploy; build cục bộ chỉ sinh `dist/_headers`, không verify được trên live (F-018, F-019).
- Trộn đại lượng stock với filter thời gian → tỷ lệ vô nghĩa (F-014; pattern tổng quát F-020).
