## Sự kiện / quy tắc

Giả định "không thể bulk fetch pluginData, phải gọi từng card" **chỉ đúng với client library** (`t.cards('all')` không trả pluginData). Với REST API thì bulk-fetch được:

```
GET /1/boards/{id}/cards?filter=all&pluginData=true
```

trả về mọi card trong 1 request, mỗi card kèm mảng `pluginData` inline. `value` là JSON string chứa `est` + `log_<memberId>`, khớp codec hiện tại.

Đã verify thực tế trên board akachan (06/06/2026): 1 request lấy đủ 115 card (71 mở + 44 archive). Đường nested qua `/lists?cards=all&pluginData=true` thì KHÔNG chạy, nhưng `/boards/{id}/cards?pluginData=true` trực tiếp thì chạy.

Hệ quả kiến trúc: dashboard thống kê **không cần cache** board-scope. Fetch tươi mỗi lần mở, tổng hợp client-side. Né luôn trần board-scope 8192 và rate limit (1 request cho board ≤1000 card).

## Khi nào liên quan

Khi cần đọc pluginData của nhiều card cùng lúc (dashboard, báo cáo, tổng hợp cross-card). Đừng lặp lại sai lầm thiết kế cache vì tưởng phải gọi từng card.

## Nguồn

Phiên grill thiết kế dashboard 2026-06-06. Test thực tế bằng curl + trello skill trên board akachan. Trùng khớp doc Trello REST API (board endpoint có param `card_pluginData`, nested `/cards` có `pluginData=true`).
