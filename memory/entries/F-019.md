## Sự kiện / quy tắc

**1. Cần `wrangler.jsonc` để serve static.** Workers Builds (Git integration trên dashboard) chạy deploy command `npx wrangler deploy`, lệnh này đọc `wrangler.jsonc` trong repo. Thiếu file → deploy fail không rõ lý do. Static site (Vite build ra `dist/`) config tối thiểu:

```jsonc
{
  "name": "ten-project",
  "compatibility_date": "2026-06-06",
  "assets": { "directory": "./dist" }
}
```

Verify dry-run trước push: `npx wrangler deploy --dry-run`, phải thấy "Read N files from the assets directory".

**2. Tự build+deploy mỗi git push, URL cố định.** Sau khi kết nối repo GitHub:
- Mỗi `git push` lên production branch (`main`) → Cloudflare tự clone → `npm install` → build command → deploy command. Không thao tác tay.
- Branch khác (nếu bật "Builds for non-production branches") → preview URL riêng, không đụng production.
- **URL production CỐ ĐỊNH** qua các lần deploy → chỉ cập nhật connector URL trong Trello một lần (xem F-003). URL: `https://<name>.<subdomain>.workers.dev/index.html`.
- Lần đầu vẫn phải push thủ công để đưa file config lên GitHub.

**3. Security header cũng đi qua cơ chế này** (xem F-018) và chỉ áp dụng sau deploy.

## Khi nào liên quan

Mỗi lần deploy static site (Vite, CRA, Next.js export...) lên Cloudflare Workers qua Git integration; khi giải thích quy trình CI/CD cho team.
