## Sự kiện / quy tắc

Khi dùng Trello REST API helper (`t.getRestApi()`), chỉ truyền `{ appKey, appName }` vào `TrelloPowerUp.initialize(...)` là chưa đủ.

Mỗi iframe phụ mở từ Power-Up cũng phải gọi:

```typescript
const t = window.TrelloPowerUp.iframe({
  appKey: APP_KEY,
  appName: APP_NAME,
});
```

Nếu iframe phụ gọi `TrelloPowerUp.iframe()` không tham số rồi dùng `t.getRestApi()`, Trello báo:

```text
To use the API helper, make sure you specify appKey and appName when you call TrelloPowerUp.iframe.
```

Quy tắc thực hành:

- Connector dùng REST API trong capability: truyền options ở `initialize`.
- Popup/modal/dashboard iframe dùng REST API: truyền options ở `iframe`.
- `getRestApi()` có thể trả object hoặc Promise, nên UI nên `await t.getRestApi?.()`.

## Khi nào liên quan

Khi thêm dashboard, báo cáo, export, hoặc bất kỳ iframe phụ nào cần gọi Trello REST API.

Đặc biệt liên quan tới `src/ui/dashboard.ts`, vì dashboard fetch board card/list qua REST API.

## Nguồn

Phiên debug 2026-06-07. Lỗi xuất hiện khi mở dashboard: API helper yêu cầu `appKey` và `appName` tại `TrelloPowerUp.iframe`.

Fix đã áp dụng tại `src/ui/dashboard.ts`: truyền `APP_KEY`, `APP_NAME` vào `iframe`, thêm helper `restApiClient()` để `await getRestApi`.

Nguồn ngoài: Atlassian Trello REST API Client docs, mục Client Initialization.
