## Sự kiện / quy tắc

**1. Cơ chế đặt header.** Project deploy như static assets (`wrangler.jsonc` chỉ có `assets.directory: ./dist`, không Worker script). Cloudflare Workers Static Assets đọc file `_headers` ở GỐC thư mục assets (cú pháp giống Cloudflare Pages). Thuận duyên nhất: đặt `public/_headers`, Vite tự copy nguyên file (kể cả tên bắt đầu `_`) sang `dist/_headers` khi build. Không cần viết Worker script.

**2. Dùng CSP `frame-ancestors`, KHÔNG `X-Frame-Options`.** Power-Up là iframe Trello nhúng cross-origin (`https://trello.com`). `X-Frame-Options: DENY/SAMEORIGIN` chặn nhúng → Power-Up VỠ hoàn toàn. `ALLOW-FROM` đã deprecated. Cách đúng: CSP `frame-ancestors https://trello.com https://*.trello.com`. securityheaders.com vẫn báo "thiếu X-Frame-Options" (chấm theo checklist cũ) nhưng KHÔNG được thêm — tradeoff chấp nhận: chức năng > 1 dòng report.

**3. HSTS < 365 ngày.** Reviewer Trello yêu cầu `max-age` < 365 ngày → dùng `max-age=15552000` (180 ngày). `includeSubDomains` trên `*.workers.dev` chỉ ảnh hưởng subdomain của chính host đó, an toàn.

**4. CSP đầy đủ đang dùng (1 dòng trong `_headers`):**

```
default-src 'self'; script-src 'self' https://p.trellocdn.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src https://fonts.gstatic.com; img-src 'self' data:; connect-src 'self' https://api.trello.com; frame-ancestors https://trello.com https://*.trello.com; base-uri 'self'; form-action 'self'; object-src 'none'
```

- `script-src` cần `https://p.trellocdn.com` (power-up.min.js).
- `style-src` cần `'unsafe-inline'` vì JS set inline `style.width` cho progress/breakdown bar + Google Fonts stylesheet.
- `connect-src` cần `https://api.trello.com` (REST trong fetch-board.ts). `t.member`/`t.get` đi qua postMessage tới parent, KHÔNG tính vào connect-src.

**5. Chỉ áp dụng sau deploy.** Header chỉ có hiệu lực SAU khi git push → Workers Builds (xem F-019). Build cục bộ chỉ sinh `dist/_headers`, cần verify live bằng securityheaders.com sau lần deploy đầu.

## Khi nào liên quan

Khi thêm/sửa HTTP header (security, cache, CORS) cho Cloudflare static-asset Worker; khi reviewer (Trello, securityheaders.com) báo thiếu HSTS/CSP; khi Power-Up đột nhiên không render trong Trello sau khi siết security header.
