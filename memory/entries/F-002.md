## Sự kiện / quy tắc

Khi tsconfig bật `"noUncheckedIndexedAccess": true`, truy cập `arr[i]` trả về `T | undefined` thay vì `T`. TypeScript báo lỗi nếu dùng trực tiếp mà không guard.

Hay gặp nhất khi TDD: viết test trước với `groups[0].subtotal`, `groups[1].rows` rồi tsc mới báo lỗi sau.

Hai cách sửa:
1. **Non-null assertion**: `groups[0]!.subtotal` — dùng khi chắc mảng không rỗng (ví dụ test fixture cố định).
2. **Guard**: `const g = groups[0]; if (!g) return;` — dùng trong code production.

Trong file test (fixture cố định), `!` là đủ và không làm mất ý nghĩa test.

## Khi nào liên quan

Mỗi khi viết test Vitest với tsconfig strict (noUncheckedIndexedAccess). Đặc biệt khi test truy cập phần tử mảng theo index.
