## Sự kiện / quy tắc

Project deploy như static assets (`wrangler.jsonc` chỉ có `assets.directory: ./dist`, không có Worker script). Cloudflare Workers Static Assets đọc file `_headers` ở **gốc thư mục assets** để gắn HTTP header — cú pháp giống Cloudflare Pages.

Cách làm thuận duyên nhất: đặt `public/_headers`, Vite tự copy nguyên file (kể cả tên bắt đầu bằng `_`) sang `dist/_headers` khi build. Không cần viết Worker script.

Cú pháp:

```
/*
  Strict-Transport-Security: max-age=15552000; includeSubDomains
  Content-Security-Policy: <một dòng>
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=(), interest-cohort=()
```

Lưu ý:
- HSTS reviewer Trello yêu cầu "< 365 days" -> dùng `max-age=15552000` (180 ngày). `includeSubDomains` trên `*.workers.dev` chỉ ảnh hưởng subdomain của chính host đó, an toàn.
- Header chỉ áp dụng **sau khi deploy** (git push -> Cloudflare Workers Builds, xem F-004). Build cục bộ chỉ sinh ra `dist/_headers`, không tự verify được trên live.

## Khi nào liên quan

Khi cần thêm/sửa HTTP header (security, cache, CORS) cho site này hoặc bất kỳ Cloudflare static-asset Worker nào. Khi reviewer (Trello, securityheaders.com) báo thiếu HSTS/CSP.

## Nguồn

Phiên xử lý feedback review Power-Up của Trello 2026-06-16. File `public/_headers`. Cần verify lại trên live bằng securityheaders.com sau lần deploy đầu tiên (chưa verify tại thời điểm capture).
